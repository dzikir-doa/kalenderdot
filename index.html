Kebijakan Privasi

Terima kasih telah menggunakan KalenderDot. Kami sangat menghargai kepercayaan Anda dan berkomitmen penuh untuk melindungi privasi serta keamanan data pribadi Anda. Kebijakan Privasi ini menjelaskan bagaimana aplikasi kami mengelola data Anda.

🔒 Prinsip Utama Privasi Kami: Seluruh catatan kegiatan dan data Anda tersimpan 100% secara lokal di perangkat Anda sendiri. Kami tidak memiliki server eksternal dan tidak pernah mengumpulkan atau menjual data pribadi Anda.

1. Pengumpulan dan Penyimpanan Data

KalenderDot dirancang sebagai aplikasi yang mengutamakan privasi penuh penggunanya:

  • Penyimpanan Lokal: Semua data kegiatan yang Anda catat menggunakan indikator visual dot tersimpan langsung di dalam penyimpanan internal perangkat Anda.
  • Tanpa Server Eksternal: Kami tidak menyediakan atau menggunakan server cloud untuk memproses, menyimpan, atau mencadangkan data Anda secara otomatis.
  • Tanpa Akun: Aplikasi ini tidak memerlukan pendaftaran akun, pembuatan profil, atau login menggunakan alamat email/layanan pihak ketiga.

2. Fitur Berbagi Data (Share)

Aplikasi ini menyediakan fitur opsional bagi Anda untuk membagikan catatan kegiatan Anda:

  • Ekspor Gambar: Anda dapat mengunduh atau membagikan ringkasan visual kegiatan Anda dalam bentuk file gambar (image).
  • Ekspor/Impor JSON: Anda dapat mencadangkan atau memindahkan data kegiatan Anda sendiri menggunakan file format .JSON.

Proses pembagian data ini sepenuhnya berada di bawah kendali Anda. File gambar atau JSON hanya disebarkan ke platform atau aplikasi lain jika Anda sendiri yang memilih untuk membagikannya.

3. Pembelian Aplikasi (Model Berbayar)

KalenderDot adalah aplikasi berbayar sekali beli (pay once) dengan harga terjangkau tanpa biaya tersembunyi. Transaksi pembayaran Anda diproses secara aman oleh Google Play Store. Kami tidak pernah menyimpan atau memiliki akses ke informasi finansial, kartu kredit, atau rekening bank Anda.

4. Izin Perangkat (Permissions)

Aplikasi ini hanya meminta izin perangkat yang relevan untuk mendukung fungsi utamanya, seperti akses penyimpanan media (hanya jika diperlukan saat Anda menyimpan/mengeksport gambar atau file .JSON ke memori ponsel Anda).

5. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu jika terdapat pembaruan fitur pada aplikasi. Perubahan akan selalu ditampilkan pada halaman ini dengan tanggal pembaruan yang disesuaikan.
